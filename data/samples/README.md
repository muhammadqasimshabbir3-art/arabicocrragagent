# Sample documents (free / open source)

| File | License | Notes |
|------|---------|--------|
| `arabic_admin_circular.pdf` | MIT (authored in-repo) | Generated by `scripts/make_arabic_sample_pdf.py` — digital Arabic text layer for RAG smoke tests |

Generate / refresh:

```bash
uv run python scripts/make_arabic_sample_pdf.py
uv run python scripts/seed_arabic_sample.py
```

The seed script embeds with **BGE-M3**, stores vectors in **persistent Chroma** (`data/chroma`), and retrieves sample questions.
